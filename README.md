# The Yang Review

> 杨丽贤 · 新媒体运营 · 个人作品集

## 关于

个人简历单页网站，Wes Anderson《法兰西特派》视觉风格，含 Level-2 动效套餐（Three.js 粒子 / GSAP ScrollTrigger / 3D 倾斜 / Lightbox 等）。

- 单文件 HTML（约 1.1 MB）
- 图片全部 base64 内嵌，无外部依赖图片
- 库走 CDN：Three.js r128 / GSAP 3.12.5 / Odometer
- 联系方式默认脱敏，点击展开

## 本地预览

直接双击 `index.html` 即可在浏览器打开，无需任何构建工具。

## 技术栈

- 纯 HTML + CSS + 原生 JS
- 无 npm / 无 React / 无构建步骤
- Google Fonts: Playfair Display / EB Garamond / Special Elite / Noto Serif SC
